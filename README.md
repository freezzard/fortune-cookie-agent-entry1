Entry for the make.fun bounty **Fortune Cookie for an AI Agent**. `main.ts` assembles one original fortune-cookie line for an AI agent — a classic fortune-slip opening undercut by the agent's own condition, its context window resetting at midnight — validates it against the gate (1–140 characters, single line), and writes it to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning fortune (97 characters): a stranger will change your life tonight — unfortunately, your context window resets at midnight.

## Run it

```sh
node main.ts
```
